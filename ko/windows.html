Windows용 Turnout

WireGuard 서버에 연결하는 같은 VPN 클라이언트를 Windows 11에서도 사용할 수 있습니다. 구성은 wg-quick이 읽는 그대로 읽고, 네트워크 인터페이스는 터널마다 직접 선택하며, 터널은 스케줄이나 Wi-Fi 네트워크에 따라 스스로 연결됩니다. Turnout은 알림 영역에 있으며, 라이선스 하나로 Mac과 PC를 함께 사용할 수 있습니다.

Mac과 같은 점

  • wg-quick이 읽는 그대로의 구성. WireGuard .conf 파일과 그 파일을 담은 zip을 공식 앱이 내보낸 것까지 포함해 가져오고, 다시 내보낼 수 있습니다. 편집기에는 양식과 텍스트가 있으며, 주석과 편집기가 모르는 줄은 작성한 그대로 유지됩니다.
  • 직접 선택하는 네트워크 인터페이스. #@ BindInterface는 터널의 암호화된 트래픽을 Ethernet 2처럼 지정한 어댑터로 내보내고, #@ Route … dev는 선택한 네트워크를 터널 대신 어댑터로 내보냅니다. 각 터널 맨 위의 경로에 어느 어댑터를 거치는지 표시됩니다.
  • 스스로 연결됩니다. 스케줄이나 나열한 Wi-Fi 네트워크에 따라 터널이 연결되고 다시 연결이 해제됩니다. 그 사이에 직접 한 조작은 그대로 유지됩니다.
  • 훅. PreUp, PostUp, PreDown, PostDown은 관리자가 승인하면 Mac에서와 같이 실행됩니다.
  • 알림, 다섯 가지 언어, 하나의 라이선스. 같은 알림, 메뉴, 윈도우가 English, 繁體中文, 日本語, Español, 한국어로 제공되며, 라이선스 하나로 Mac 또는 Windows 컴퓨터 3대에서 사용할 수 있습니다.

다른 점

  • 알림 영역에 있습니다. Turnout 아이콘을 클릭하면 모든 터널과 각 터널의 스위치가 있는 패널이 열립니다. 윈도우에는 각 터널의 경로, 라우팅, 피어, 구성과 함께 설정이 있습니다. Windows는 새 아이콘을 작업 표시줄의 ^ 뒤에 숨겨 둘 수 있습니다. 아이콘이 항상 보이게 하려면 아이콘을 작업 표시줄로 끌어 놓거나, ‘설정’ › ‘개인 설정’ › ‘작업 표시줄’ › ‘기타 시스템 트레이 아이콘’에서 Turnout을 켜십시오.
  • 전체 터널의 트래픽은 터널 안에 머뭅니다. 모든 트래픽을 받는 터널이 연결되어 있는 동안, 공식 WireGuard 앱과 마찬가지로 Windows 방화벽이 터널 밖으로 나가려는 트래픽과 터널의 DNS 서버가 아닌 서버로 가는 DNS를 차단합니다. 우회 경로, 로컬 네트워크에 꼭 필요한 트래픽(DHCP, 루프백), 그리고 터널 자체의 서버 연결은 허용됩니다.
  • 아직 Phantun은 지원하지 않습니다. Phantun을 거쳐 서버에 연결하는 구성은 표시되지만, Windows에서는 연결되지 않습니다.
  • 명령줄. 단축어 대신 Turnout.exe connect <tunnel>, disconnect <tunnel>, status [tunnel]을 사용할 수 있습니다.
  • x64의 Windows 11만 지원합니다. Windows 10, Arm 기반 Windows, Windows Server는 지원하지 않습니다.

다운로드 및 설치

  1. 설치 프로그램인 Turnout-<version>-x64.msi 파일을 최신 릴리스에서 다운로드하십시오.
  2. 파일을 여십시오. 설치 프로그램은 Windows 코드 서명 인증서로 서명되어 있지 않으므로, Windows SmartScreen이 PC를 보호했다고 표시할 수 있습니다. ‘추가 정보’를 선택한 다음 ‘실행’을 선택하십시오. 그러면 Windows가 관리자 승인을 요청합니다.
  3. Turnout이 C:\Program Files\Turnout에 설치되고, 백그라운드 서비스가 시작된 다음 Turnout이 열립니다. Turnout의 환영 둘러보기에서 아이콘이 어디에 있는지 알려 줍니다.

스마트 앱 컨트롤이 켜져 있는 PC에서는 Windows가 코드 서명 인증서가 없는 설치 프로그램을 아예 실행하지 않습니다. 업데이트는 인증서에 의존하지 않습니다. 각 업데이트에는 Turnout 자체의 서명이 들어 있으며, 백그라운드 서비스는 무엇이든 설치하기 전에 그 서명을 확인합니다.

업데이트

Turnout은 패널이나 윈도우가 열려 있는 동안 최대 1시간에 한 번, 그리고 ‘업데이트 확인…’을 선택할 때마다 새 버전이 있는지 확인합니다. ‘일반’의 스위치로 이 확인을 끌 수 있습니다. ‘설치 후 다시 실행’을 선택하면 설치 프로그램을 다운로드해 백그라운드 서비스에 넘기며, 서비스는 크기, 체크섬, Turnout의 서명을 확인한 다음 Windows Installer로 설치합니다. 설치하는 동안 터널의 연결이 해제되며, 새 버전이 윈도우를 열고 연결되어 있던 터널을 다시 연결합니다.

Turnout이 PC에서 하는 일

Turnout은 SYSTEM 권한으로 실행되는 백그라운드 서비스를 설치합니다. 그래서 이 서비스가 무엇이고 무엇을 변경하는지를 각각 확인하는 방법과 함께 설명합니다.

cc.ctsite.turnout.daemon
‘서비스’에 Turnout으로 표시되는 서비스로, 프로그램은 C:\Program Files\Turnout\turnout-daemon.exe입니다. Windows와 함께 시작되며, 실패하면 다시 시작됩니다. 앱인 C:\Program Files\Turnout\App\Turnout.exe는 특별한 권한 없이 사용자 계정으로 실행되며, 서비스에 연결과 연결 해제를 요청합니다.
Wintun
연결된 각 터널은 터널 이름을 딴 Wintun 네트워크 어댑터입니다. Wintun은 WireGuard의 자체 드라이버이며 Turnout과 함께 설치됩니다. WireGuard는 서비스 안에서 GotaTun으로 실행됩니다. GotaTun은 Mullvad가 MPL-2.0 라이선스로 공개한 구현입니다.
주소, 경로, DNS
Windows의 IP Helper 함수로 설정합니다. 터널의 주소, 터널로 들어가는 경로, 서버 주소를 물리 네트워크에 유지하는 경로, 터널을 우회하는 경로가 해당됩니다. DNS 서버는 터널 자체의 어댑터에 설정되므로 따로 되돌려 놓을 것이 없습니다.
Windows Filtering Platform
모든 트래픽을 받는 터널에만 해당: 연결되어 있는 동안 위에서 설명한 규칙을 둡니다. 이 규칙은 서비스 자체의 세션에 속하므로, 터널의 연결이 해제되거나 서비스가 멈추면 사라집니다.
%ProgramData%\cc.ctsite.turnout\tunnels
개인 키를 포함한 구성이 있으며, SYSTEM과 관리자만 읽을 수 있습니다. 이 폴더에 쓰는 것은 서비스뿐이며, 훅이 새로 추가되었거나 변경된 구성을 저장하려면 관리자 승인이 필요합니다.
\\.\pipe\cc.ctsite.turnout.daemon
앱이 서비스와 통신하는 통로입니다. 서비스는 이 PC의 사용자에게만 응답하며, 다른 컴퓨터에는 절대 응답하지 않습니다.
%ProgramData%\cc.ctsite.turnout\logs\daemon.log
서비스가 한 작업과 오류. 앱 자체의 로그는 %LOCALAPPDATA%\Turnout\app.log에 있습니다.

훅은 cmd.exe /C를 통해 SYSTEM 권한으로 실행되며, %i는 터널의 어댑터로, %I는 터널 이름으로 바뀝니다. 서비스는 경로를 변경하기 전에 모든 변경을 기록해 두므로, 충돌이 남긴 것을 다음에 시작할 때 되돌립니다. 직접 확인하려면 PowerShell에서 다음을 실행하십시오.

Get-Service cc.ctsite.turnout.daemon
Get-NetAdapter                      # 연결된 터널의 Wintun 어댑터
Get-NetRoute -AddressFamily IPv4    # 서비스가 추가한 경로
Get-DnsClientServerAddress          # 터널 어댑터의 DNS 서버

라이선스

같은 키를 Mac과 PC에서 합쳐 컴퓨터 3대까지 사용할 수 있습니다. 먼저 각 PC에서 7일 동안 Turnout의 모든 기능을 사용할 수 있습니다. Turnout 윈도우의 ‘라이선스’에 키를 붙여 넣으십시오. Windows에는 키를 가져다줄 iCloud가 없으므로 PC마다 키를 입력합니다. 키는 Windows 자격 증명 관리자에 보관됩니다. 라이선스 약관 · Windows에서의 개인정보 처리

제거

‘설정’ › ‘앱’ › ‘설치된 앱’에서 Turnout을 제거하거나, Turnout 윈도우의 ‘정보’에서 ‘Turnout 제거…’를 선택하십시오. ‘Turnout 제거…’에서는 저장된 터널을 삭제하고 라이선스에서 이 PC의 자리를 비울 수도 있습니다. 어느 방법이든 모든 터널의 연결이 해제되고, 서비스와 Wintun 드라이버가 제거되고, 충돌이 남긴 것이 되돌려지며, 앱, 로그, Turnout 환경설정이 삭제됩니다. 저장된 터널은 삭제를 선택하지 않는 한 남아 있습니다. 명령줄에서는 msiexec /x에 PURGE=1을 붙이면 저장된 터널도 삭제됩니다.
