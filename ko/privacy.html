개인정보 처리방침

2026년 10월 26일 시행

Turnout에는 계정, 광고, 충돌 보고가 없으며, 사용자가 터널로 무엇을 하는지 살펴보는 기능도 전혀 없습니다. 앱이 보내는 것은 업데이트 확인과, 확인할 때마다 설치 수를 집계하는 익명 보고서 하나입니다. 스위치 하나로 둘 다 끌 수 있습니다. 라이선스를 구입한 후에는 앱이 Turnout을 판매하는 Polar를 통해 약 1주일에 한 번 라이선스도 확인합니다. 체험 기간에는 라이선스를 확인하지 않습니다.

Mac 밖으로 나가는 정보

  • 업데이트 확인. Turnout은 메뉴나 윈도우를 열 때 최대 1시간에 한 번, 그리고 ‘업데이트 확인…’을 선택할 때마다 GitHub에 최신 릴리스에 있는 작은 파일을 요청합니다. 이 요청에는 사용자나 사용자의 터널에 관한 정보가 전혀 담기지 않습니다. GitHub는 GitHub 일반 개인정보 보호정책에 설명된 대로 요청과 사용자의 IP 주소를 볼 수 있습니다. 업데이트를 설치하면 같은 곳에서 설치 프로그램을 다운로드합니다.
  • 확인할 때마다 보내는 익명 보고서. 확인할 때마다 Google Analytics(google-analytics.com)에도 이벤트 하나를 보내, 개발자가 사용 중인 설치 수와 각각의 버전을 알 수 있게 합니다. 이 이벤트에는 Turnout이 처음 사용될 때 만들어 환경설정에 보관하는 무작위 설치 ID(Mac의 하드웨어에서 만든 값이 아님), Turnout 버전과 빌드, macOS 버전, 프로세서 아키텍처, 시스템 언어, 그리고 Google Analytics가 보고서를 세션으로 묶는 데 사용하는 Turnout 시작 시각이 담깁니다. 터널, 서버, 키, 네트워크에 관한 정보는 절대 전송되지 않으며, 계정이나 사용자 ID도 없습니다. Google은 요청과 사용자의 IP 주소를 볼 수 있으며, Google의 데이터 사용 방식은 Google 개인정보처리방침에 설명되어 있습니다.
  • 라이선스. 라이선스를 구입한 후에는 Mac 활성화, 약 1주일에 한 번의 확인, Mac 제거가 Turnout을 판매하는 Polar로 전송되며, 다른 Mac에서도 라이선스를 찾을 수 있도록 라이선스가 사용자의 iCloud 계정에 보관됩니다. 체험 기간에는 Polar로 아무것도 전송되지 않습니다. 각 단계에서 보내는 정보는 라이선스 항목에 나와 있습니다.
  • 터널. 터널을 통해 보내는 트래픽은 해당 구성에 지정된 서버로 가며, 사용자와 그 서버를 운영하는 사람 사이의 일입니다. 훅은 사용자가 작성한 대로 동작합니다.

확인과 보고서를 모두 중단하려면 ‘일반’(Turnout › ‘설정…’)에서 ‘자동으로 업데이트 확인’을 끄십시오. 그러면 Turnout은 ‘업데이트 확인…’을 선택할 때만 확인하며, 보고서는 전혀 보내지 않습니다. 이 스위치는 라이선스 확인에는 영향을 주지 않으며, 라이선스 확인은 라이선스를 구입한 후에만 실행됩니다.

그 밖에는 아무것도 Mac 밖으로 나가지 않습니다. 자체 충돌 보고, 광고, 추적, 타사 SDK가 없습니다.

라이선스

Turnout은 Polar(polar.sh)가 기록상 판매자(seller of record)로서 판매합니다. Polar가 결제를 받고, 세금을 처리하고, 영수증을 발행하고, 주문 내역을 보관합니다. 체험 기간에는 Polar로 아무것도 전송되지 않으며, 업데이트 확인과 그 보고서는 평소와 같이 실행되고 체험 기간에 관해서는 아무것도 알지 못합니다. 라이선스를 구입한 후 라이선스와 관련해 전송되는 정보와 그 시점은 다음과 같습니다.

  • 구입. Polar 결제 페이지에 입력하는 정보: 이메일 주소, 이름, 카드(Stripe가 처리), 청구지 국가. Polar는 Polar 개인정보 처리방침에 따라 이 정보를 보관합니다.
  • Mac 활성화(키를 입력하거나 다른 Mac에서 키를 사용할 때): 라이선스 키, Mac에 지정하는 이름(활성화하기 전에 바꾸지 않으면 컴퓨터 이름), Mac의 모델 식별자, macOS 및 Turnout 버전, Mac 하드웨어 식별자의 단방향 해시. 이 정보는 api.polar.sh에 있는 Polar의 라이선스 서비스로 전송되며, 이 서비스는 다른 모든 요청과 마찬가지로 사용자의 IP 주소를 볼 수 있습니다.
  • 라이선스 확인(약 1주일에 한 번 Turnout의 메뉴나 윈도우를 열 때, 그리고 ‘지금 확인’을 선택할 때마다): 라이선스 키, 이 Mac의 활성화 ID, 같은 해시를 api.polar.sh로 보냅니다.
  • 라이선스에서 Mac 제거: 키와 해당 Mac의 활성화 ID를 api.polar.sh로 보냅니다.
  • 사용자의 다른 Mac. 다른 Mac에서 라이선스를 찾을 수 있도록, 키, 구입할 때 사용한 이메일 주소, 그리고 키를 사용하는 각 Mac의 이름, 모델, macOS 및 Turnout 버전, 활성화 ID, 같은 해시가 사용자 iCloud 계정의 Turnout 전용 영역(CloudKit)에 레코드로 보관됩니다. Turnout은 사용자의 다른 Mac에서 구입한 라이선스를 찾기 위해, 시작할 때와 메뉴나 윈도우를 열 때 이 레코드를 읽으며 체험 기간에도 마찬가지입니다. 레코드를 쓰는 것은 활성화, 확인 또는 제거 후뿐입니다. 이 레코드는 Apple의 표준 iCloud 보호 방식으로 저장되며 종단 간 암호화되지 않습니다. 개발자는 이 레코드를 읽을 수 없습니다. Mac이 iCloud에 로그인되어 있지 않으면 이 중 어느 것도 이루어지지 않습니다.

터널, 서버, 터널 키, 네트워크에 관한 정보는 어디에도 포함되지 않습니다. 해시는 하드웨어 식별자로 되돌릴 수 없으며, 라이선스가 사용자의 Mac들을 구별하는 데 쓰입니다. Polar에 연결할 수 없는 Mac도 계속 작동합니다. 확인에 실패했다고 해서 Turnout의 어떤 기능도 멈추지 않습니다. Turnout 윈도우의 ‘라이선스’ 패널에서 Turnout이 라이선스에 관해 보관하는 정보를 볼 수 있습니다.

위치 및 Wi-Fi 규칙

macOS는 현재 연결된 Wi-Fi 네트워크의 이름을 위치 정보로 취급합니다. Turnout은 특정 Wi-Fi 네트워크에서 터널을 연결하는 규칙을 설정할 때만 위치 접근 권한을 요청하며, 이 권한은 네트워크 이름을 읽는 데만 사용하고 사용자가 있는 위치를 알아내는 데는 절대 사용하지 않습니다. 사용자가 나열한 네트워크 이름은 Mac에 있는 해당 터널의 구성 파일에 저장되며 어디로도 전송되지 않습니다. 접근 권한은 ‘시스템 설정’ › ‘개인정보 보호 및 보안’ › ‘위치 서비스’에서 철회할 수 있습니다.

Mac에 남는 정보

  • 개인 키를 포함한 터널: root만 읽을 수 있는 /Library/Application Support/cc.ctsite.turnout/tunnels에 보관됩니다.
  • cc.ctsite.turnout 아래의 앱 환경설정: 각 네트워크 인터페이스를 표시하는 색상, 스케줄이 마지막으로 동작한 시각, 무작위 설치 ID 등.
  • 이 Mac의 키체인에 있는 라이선스 항목 cc.ctsite.turnout.license: 체험 기간이 시작된 시점, 그리고 구입한 후에는 키, 구입할 때 사용한 이메일 주소, 이 Mac의 활성화 정보, 라이선스를 마지막으로 확인한 시점. 이 항목은 이 Mac 밖으로 절대 나가지 않습니다.
  • 로그: 백그라운드 서비스가 남기는 /Library/Logs/cc.ctsite.turnout.daemon.log, 업데이트를 설치할 때 기록되는 /Library/Logs/cc.ctsite.turnout.update.log, 그리고 macOS 시스템 로그에 남는 앱의 메시지.

Turnout을 제거하면 앱, 로그, 모든 사용자의 Turnout 환경설정이 삭제되고 설치 ID도 함께 삭제되며, 원하면 저장된 터널도 삭제됩니다. 새로 설치하면 새 ID가 만들어집니다. 라이선스 항목은 키체인에 남으므로 다시 설치해도 체험 기간이 새로 시작되지 않습니다. 앱의 ‘Turnout 제거…’는 확인 창에서 다르게 선택하지 않는 한 이 Mac을 라이선스에서 제거하고 iCloud 계정에서 이 Mac의 레코드도 삭제합니다. 설치 프로그램과 터미널 스크립트는 그렇게 할 수 없으므로, 이 방법으로 제거한 후에는 다른 Mac의 ‘라이선스’ 패널이나 Polar의 고객 포털에서 해당 Mac을 제거하십시오. 다른 Mac에서 사용하는 키는 iCloud 계정에 그대로 남습니다. 제거 방법

이 웹 사이트의 분석

이 웹 사이트는 페이지 하단의 막대에서 ‘동의’를 선택한 경우에만 Google Analytics를 사용합니다. 선택하기 전이나 ‘거부’를 선택한 경우에는 분석 코드를 불러오지 않으며, Google로 아무것도 전송되지 않고 쿠키도 설정되지 않습니다.

동의하면 Google Analytics는 사용자가 본 페이지, IP 주소로 추정한 대략적인 위치(Google Analytics는 IP 주소 자체를 보관하지 않음), 브라우저 및 기기 유형, 사용자를 이 사이트로 보낸 사이트를 기록합니다. 또한 재방문을 인식하기 위해 이 사이트에 _ga라는 이름의 쿠키를 설정합니다.

이는 위에서 설명한 앱의 보고서와는 별개입니다. 여기서 선택한 내용은 앱이 보내는 정보에 영향을 주지 않으며, 앱의 스위치도 이 웹 사이트에 영향을 주지 않습니다.

선택한 내용은 브라우저에 있는 이 사이트의 저장 공간에 보관됩니다. 선택을 바꾸려면 아래 버튼을 사용하거나 브라우저에서 이 사이트의 데이터를 지우십시오. 데이터를 지우면 Google Analytics 쿠키도 삭제됩니다. Google의 데이터 사용 방식은 Google 개인정보처리방침에 설명되어 있습니다.

이 웹 사이트

이 사이트에는 분석 도구와 쿠키가 없습니다. 다른 사이트에 요청하는 것은 Turnout의 최신 버전과 출시일뿐이며, 홈페이지가 다운로드 버튼 아래에 표시하기 위해 GitHub API(api.github.com)에 요청합니다.

Google Analytics(위에서 설명한 대로 동의한 후에만 불러옴) 외에, 이 사이트가 다른 사이트에 요청하는 것은 하나뿐입니다. 홈페이지가 다운로드 버튼 아래에 표시하기 위해 GitHub API(api.github.com)에 Turnout의 최신 버전과 출시일을 요청합니다. 이 요청에는 쿠키가 포함되지 않으며, 이 사이트는 자체 쿠키를 설정하지 않습니다.

이 사이트는 GitHub Pages에서 호스팅되며, GitHub는 GitHub 일반 개인정보 보호정책에 설명된 대로 방문과 이 요청을 기록할 수 있습니다.

문의

질문과 문제는 github.com/tasict/Turnout/issues의 이슈 트래커에 올려 주십시오. 이슈는 공개되므로 개인 키, 사전 공유 키, 서버 주소, 구성 파일 전체는 포함하지 마십시오.

구입, 환불 또는 라이선스에 관해 보관되는 정보에 대한 문의는 support@ctsite.cc로 보내 주십시오.
