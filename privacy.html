Privacy policy

Effective 20 October 2026

Turnout collects nothing about you. It has no account, no analytics and no third-party SDKs, and the only connection the app itself makes is its check for updates.

What leaves your Mac

  • The update check. The app asks GitHub for a small file in Turnout's latest release when you open the menu or a window, at most once an hour, and whenever you choose Check for Updates…. The request carries nothing about you or your tunnels. GitHub sees the request and your IP address, as described in the GitHub General Privacy Statement. Installing an update downloads the installer from the same place.
  • Your tunnels. Traffic you send through a tunnel goes to the server in its config, and is between you and whoever runs that server. Hooks do what you wrote in them.

Nothing else: no analytics, no crash reporting of its own, no advertising, no tracking.

Location and Wi-Fi rules

macOS counts the name of the Wi-Fi network you are on as location. Turnout asks for Location access only when you set up a rule that connects a tunnel on certain Wi-Fi networks, and uses it only to read the network's name, never where you are. The network names you list are stored in that tunnel's config file on your Mac and are not sent anywhere. You can take access back in System Settings › Privacy & Security › Location Services.

What stays on your Mac

  • Your tunnels, private keys included, in /Library/Application Support/cc.ctsite.wggui/tunnels, which only root can read.
  • The app's preferences, under cc.ctsite.wggui: things like the colour each network interface is shown in, and when a schedule last acted.
  • Logs: /Library/Logs/cc.ctsite.wggui.daemon.log from the background service, /Library/Logs/cc.ctsite.wggui.update.log when an update is installed, and the app's messages in the macOS system log.

Uninstalling Turnout deletes the app, its logs and every user's Turnout preferences, and the saved tunnels too if you choose. How to uninstall

This website

This site has no analytics, no cookies and no scripts, and loads nothing from other sites. It is hosted on GitHub Pages, and GitHub may log visits as described in the GitHub General Privacy Statement.

Contact

Questions and problems go to the issue tracker at github.com/tasict/Turnout/issues. Issues are public: leave out private keys, preshared keys, server addresses and whole config files.

Changes

If this policy changes, the new version will be posted on this page with a new effective date. It is available in English and 繁體中文; if the two differ, the English version applies.
