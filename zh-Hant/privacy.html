隱私權政策

生效日期：2026 年 10 月 20 日

Turnout 不收集任何關於你的資料。它沒有帳號、沒有分析工具，也沒有第三方 SDK；App 本身唯一的網路連線，就是檢查更新。

哪些東西會離開你的 Mac

  • 檢查更新。App 會向 GitHub 索取 Turnout 最新版本中的一個小檔案：在你打開選單或視窗時，最多每小時一次，以及你選擇 Check for Updates… 的時候。請求不含任何關於你或你的通道的資訊。GitHub 看得到這個請求和你的 IP 位址，相關說明請見 GitHub 一般隱私權聲明。安裝更新時，安裝程式也從同一個地方下載。
  • 你的通道。你透過通道傳送的流量會送到設定檔中的伺服器，那是你和該伺服器營運者之間的事。hook 則做你寫在裡面的事。

除此之外沒有別的：沒有分析工具、沒有自家的當機回報、沒有廣告，也沒有追蹤。

定位與 Wi-Fi 規則

macOS 把你所在 Wi-Fi 網路的名稱視為位置資訊。只有在你設定「連上特定 Wi-Fi 網路時連線」這類規則時，Turnout 才會要求定位權限，而且只用來讀取網路名稱，從不用來得知你在哪裡。你列出的網路名稱存在該通道於 Mac 上的設定檔裡，不會傳送到任何地方。你可以在「系統設定 › 隱私權與安全性 › 定位服務」中收回權限。

哪些東西留在你的 Mac 上

  • 你的通道（包括私鑰），位於 /Library/Application Support/cc.ctsite.wggui/tunnels，只有 root 能讀取。
  • App 的偏好設定，存在 cc.ctsite.wggui 底下，例如每個網路介面顯示的顏色，以及排程上次執行的時間。
  • 記錄檔：背景服務的 /Library/Logs/cc.ctsite.wggui.daemon.log、安裝更新時的 /Library/Logs/cc.ctsite.wggui.update.log，以及 App 寫在 macOS 系統記錄中的訊息。

這個網站

本網站沒有分析工具、沒有 Cookie、沒有指令碼，也不會從其他網站載入任何東西。它架設在 GitHub Pages 上，GitHub 可能會記錄造訪，詳見 GitHub 一般隱私權聲明。

聯絡方式

問題與疑問請到 github.com/tasict/Turnout/issues 回報。Issue 是公開的：請不要貼上私鑰、預共享金鑰、伺服器位址或完整的設定檔。
