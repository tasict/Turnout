隱私權政策

生效日期：2026 年 10 月 26 日

Turnout 沒有帳號、沒有廣告、沒有當機回報，也不會去看你怎麼使用通道。App 會送出的，只有檢查更新，以及每次檢查時附帶的一份匿名回報，用來計算安裝數。一個開關就能把兩者都關掉。買了授權之後，它還會大約每週一次向販售 Turnout 的 Polar 檢查授權。試用期間不做任何授權檢查。

哪些東西會離開你的 Mac

  • 檢查更新。在你打開選單或視窗時（最多每小時一次），以及你選擇「檢查更新項目⋯」的時候，Turnout 會向 GitHub 索取它最新版本中的一個小檔案。請求不含任何關於你或你的通道的資訊。GitHub 看得到這個請求和你的 IP 位址，相關說明請見 GitHub 一般隱私權聲明。安裝更新時，安裝程式也從同一個地方下載。
  • 每次檢查附帶的匿名回報。每次檢查時，App 也會送出一個事件給 Google Analytics（google-analytics.com），讓開發者知道有多少份 Turnout 在使用、各是哪個版本。內容包括：Turnout 第一次使用時隨機產生、存在偏好設定裡的安裝 ID（不是從你 Mac 的硬體推算出來的）、Turnout 的版本與建置編號、macOS 版本、處理器架構、系統語言，以及 Turnout 的啟動時間（Google Analytics 用它把回報歸入同一個工作階段）。絕不會送出任何關於你的通道、伺服器、金鑰或網路的資訊，也沒有帳號或使用者 ID。Google 看得到這個請求和你的 IP 位址，它如何使用這些資料，請見 Google 隱私權政策。
  • 授權。買了授權之後，啟用一部 Mac、大約每週一次的檢查，以及移除一部 Mac，都會連到販售 Turnout 的 Polar；授權也會存在你的 iCloud 帳號裡，讓你的其他 Mac 找得到。試用期間不會傳送任何東西給 Polar。每一步會送出什麼，列在下方的授權一節。
  • 你的通道。你透過通道傳送的流量會送到設定檔中的伺服器，那是你和該伺服器營運者之間的事。hook 則做你寫在裡面的事。

想同時停止檢查與回報，請在「一般」（「Turnout」›「設定⋯」）關掉「自動檢查更新項目」。之後 Turnout 只會在你選擇「檢查更新項目⋯」時檢查，而且完全不送出回報。這個開關不影響授權檢查；授權檢查只在你買了授權之後才會進行。

除此之外沒有別的東西會離開你的 Mac：沒有自家的當機回報、沒有廣告、沒有追蹤，也沒有第三方 SDK。

授權

Turnout 由 Polar（polar.sh）以賣方身分販售：收款、稅務和收據都由 Polar 處理，你的訂單也由它保存。試用期間不會傳送任何東西給 Polar；檢查更新與附帶的回報照常運作，也完全不知道試用的事。買了授權之後，關於授權會送出的東西和時機如下：

  • 購買。你在 Polar 結帳頁面填寫的資料：電子郵件地址、姓名、信用卡（由 Stripe 處理）和帳單地址所在的國家。這些資料由 Polar 依 Polar 隱私權政策保存。
  • 啟用一部 Mac（輸入授權金鑰，或在另一部 Mac 上使用它時）：授權金鑰；你為這部 Mac 取的名稱（預設是電腦名稱，啟用前可以修改）；Mac 的機型識別碼；macOS 與 Turnout 的版本；以及由 Mac 的硬體識別碼算出的單向雜湊值。這些會送到 Polar 的授權服務 api.polar.sh；和任何請求一樣，它看得到你的 IP 位址。
  • 檢查授權（大約每週一次，在你打開 Turnout 的選單或視窗時，以及你手動要求檢查時）：授權金鑰、這部 Mac 的啟用 ID，以及同一個雜湊值，送到 api.polar.sh。
  • 從授權中移除一部 Mac：授權金鑰和那部 Mac 的啟用 ID，送到 api.polar.sh。
  • 你的其他 Mac。為了讓你的其他 Mac 找到授權，授權金鑰、購買時用的電子郵件地址，以及每部使用它的 Mac 的名稱、機型、macOS 與 Turnout 版本、啟用 ID 和同一個雜湊值，會以記錄的形式存在你 iCloud 帳號中屬於 Turnout 的區域（CloudKit）。Turnout 啟動時，以及你打開它的選單或視窗時，會讀取這些記錄（試用期間也會，好找到你在另一部 Mac 上買的授權）；只有在啟用、檢查或移除之後才會寫入。它們受 Apple 標準的 iCloud 保護，但不是端對端加密，開發者也讀不到。這部 Mac 沒有登入 iCloud 時，這些都不會發生。

其中絕不包含任何關於你的通道、伺服器、通道金鑰或網路的資訊。雜湊值無法還原成硬體識別碼，它只是讓授權分得出你的各部 Mac。連不上 Polar 的 Mac 照樣能用：Turnout 不會因為檢查失敗而停止任何功能。Turnout 視窗中的「授權」面板會顯示 Turnout 保存了哪些授權資料。

定位與 Wi-Fi 規則

macOS 把你所在 Wi-Fi 網路的名稱視為位置資訊。只有在你設定「連上特定 Wi-Fi 網路時連線」這類規則時，Turnout 才會要求定位權限，而且只用來讀取網路名稱，從不用來得知你在哪裡。你列出的網路名稱存在該通道於 Mac 上的設定檔裡，不會傳送到任何地方。你可以在「系統設定 › 隱私權與安全性 › 定位服務」中收回權限。

哪些東西留在你的 Mac 上

  • 你的通道（包括私鑰），位於 /Library/Application Support/cc.ctsite.turnout/tunnels，只有 root 能讀取。
  • App 的偏好設定，存在 cc.ctsite.turnout 底下，例如每個網路介面顯示的顏色、排程上次執行的時間，以及隨機產生的安裝 ID。
  • 這部 Mac 鑰匙圈裡的授權項目 cc.ctsite.turnout.license：試用開始的時間；買了授權之後，還有授權金鑰、購買時用的電子郵件地址、這部 Mac 的啟用資料，以及上次檢查授權的時間。它從不離開這部 Mac。
  • 記錄檔：背景服務的 /Library/Logs/cc.ctsite.turnout.daemon.log、安裝更新時的 /Library/Logs/cc.ctsite.turnout.update.log，以及 App 寫在 macOS 系統記錄中的訊息。

解除安裝 Turnout 會刪除 App、它的記錄檔，以及每位使用者的 Turnout 偏好設定（安裝 ID 也一併刪除）；若你選擇，也會刪除已儲存的通道。重新安裝會產生新的 ID。鑰匙圈裡的授權項目會保留，所以重新安裝不會重新開始試用。從 App 選擇「解除安裝Turnout⋯」時，它也會把這部 Mac 從你的授權中移除，並刪除它在你 iCloud 帳號中的記錄（確認時可以選擇不要這麼做）；安裝程式和終端機指令稿做不到這一點，用這兩種方式解除安裝後，請在另一部 Mac 的「授權」面板或 Polar 的客戶入口移除這部 Mac。你其他 Mac 使用的授權金鑰仍會留在你的 iCloud 帳號中。如何解除安裝

本網站的分析

只有在你點選頁面底部提示列中的「接受」之後，本網站才會使用 Google Analytics。在那之前，或你選擇「拒絕」時，不會載入任何分析程式碼，不會傳送任何資料給 Google，也不會設定任何 Cookie。

接受之後，Google Analytics 會記錄你瀏覽的頁面、由 IP 位址推算出的大略位置（Google Analytics 不會保留位址本身）、你的瀏覽器與裝置類型，以及你從哪個網站連過來。它會在本網站設定名為 _ga 的 Cookie，用來辨認再次造訪。

這和上面 App 的回報是分開的：你在這裡的選擇不會改變 App 送出的內容，App 裡的開關也不會影響本網站。

你的選擇存在瀏覽器為本網站保留的儲存空間中。想改變選擇，可以按下方的按鈕，或在瀏覽器中清除本網站的資料（這也會一併刪除 Google Analytics 的 Cookie）。Google 如何使用這些資料，請見 Google 隱私權政策。

這個網站

本網站沒有分析工具，也沒有 Cookie。它唯一向其他網站要的，是 Turnout 的最新版本和發布日期：首頁會向 GitHub 的 API（api.github.com）查詢，顯示在下載按鈕下方。

除了 Google Analytics（只在你接受之後才會載入，詳見上方說明）之外，本網站只向另一個網站要一樣東西：首頁會向 GitHub 的 API（api.github.com）查詢 Turnout 的最新版本和發布日期，顯示在下載按鈕下方。這個查詢不帶任何 Cookie，本網站本身也不設定 Cookie。

它架設在 GitHub Pages 上，GitHub 可能會記錄造訪和上述查詢，詳見 GitHub 一般隱私權聲明。

聯絡方式

問題與疑問請到 github.com/tasict/Turnout/issues 回報。Issue 是公開的：請不要貼上私鑰、預共享金鑰、伺服器位址或完整的設定檔。

購買、退款，或保存了哪些與你授權有關的資料等問題，請寄信到 support@ctsite.cc。
