隱私權政策

生效日期：2026 年 10 月 20 日

Turnout 沒有帳號、沒有廣告、沒有當機回報，也不會去看你怎麼使用通道。App 會送出的，只有檢查更新，以及每次檢查時附帶的一份匿名回報，用來計算安裝數。一個開關就能把兩者都關掉。

哪些東西會離開你的 Mac

  • 檢查更新。在你打開選單或視窗時（最多每小時一次），以及你選擇「檢查更新項目⋯」的時候，Turnout 會向 GitHub 索取它最新版本中的一個小檔案。請求不含任何關於你或你的通道的資訊。GitHub 看得到這個請求和你的 IP 位址，相關說明請見 GitHub 一般隱私權聲明。安裝更新時，安裝程式也從同一個地方下載。
  • 每次檢查附帶的匿名回報。每次檢查時，App 也會送出一個事件給 Google Analytics（google-analytics.com），讓開發者知道有多少份 Turnout 在使用、各是哪個版本。內容包括：Turnout 第一次使用時隨機產生、存在偏好設定裡的安裝 ID（不是從你 Mac 的硬體推算出來的）、Turnout 的版本與建置編號、macOS 版本、處理器架構、系統語言，以及 Turnout 的啟動時間（Google Analytics 用它把回報歸入同一個工作階段）。絕不會送出任何關於你的通道、伺服器、金鑰或網路的資訊，也沒有帳號或使用者 ID。Google 看得到這個請求和你的 IP 位址，它如何使用這些資料，請見 Google 隱私權政策。
  • 你的通道。你透過通道傳送的流量會送到設定檔中的伺服器，那是你和該伺服器營運者之間的事。hook 則做你寫在裡面的事。

想同時停止檢查與回報，請在「一般」（「Turnout」›「設定⋯」）關掉「自動檢查更新項目」。之後 Turnout 只會在你選擇「檢查更新項目⋯」時檢查，而且完全不送出回報。

除此之外沒有別的東西會離開你的 Mac：沒有自家的當機回報、沒有廣告、沒有追蹤，也沒有第三方 SDK。

定位與 Wi-Fi 規則

macOS 把你所在 Wi-Fi 網路的名稱視為位置資訊。只有在你設定「連上特定 Wi-Fi 網路時連線」這類規則時，Turnout 才會要求定位權限，而且只用來讀取網路名稱，從不用來得知你在哪裡。你列出的網路名稱存在該通道於 Mac 上的設定檔裡，不會傳送到任何地方。你可以在「系統設定 › 隱私權與安全性 › 定位服務」中收回權限。

哪些東西留在你的 Mac 上

  • 你的通道（包括私鑰），位於 /Library/Application Support/cc.ctsite.turnout/tunnels，只有 root 能讀取。
  • App 的偏好設定，存在 cc.ctsite.turnout 底下，例如每個網路介面顯示的顏色、排程上次執行的時間，以及隨機產生的安裝 ID。
  • 記錄檔：背景服務的 /Library/Logs/cc.ctsite.turnout.daemon.log、安裝更新時的 /Library/Logs/cc.ctsite.turnout.update.log，以及 App 寫在 macOS 系統記錄中的訊息。

本網站的分析

只有在你點選頁面底部提示列中的「接受」之後，本網站才會使用 Google Analytics。在那之前，或你選擇「拒絕」時，不會載入任何分析程式碼，不會傳送任何資料給 Google，也不會設定任何 Cookie。

接受之後，Google Analytics 會記錄你瀏覽的頁面、由 IP 位址推算出的大略位置（Google Analytics 不會保留位址本身）、你的瀏覽器與裝置類型，以及你從哪個網站連過來。它會在本網站設定名為 _ga 的 Cookie，用來辨認再次造訪。

這和上面 App 的回報是分開的：你在這裡的選擇不會改變 App 送出的內容，App 裡的開關也不會影響本網站。

你的選擇存在瀏覽器為本網站保留的儲存空間中。想改變選擇，可以按下方的按鈕，或在瀏覽器中清除本網站的資料（這也會一併刪除 Google Analytics 的 Cookie）。Google 如何使用這些資料，請見 Google 隱私權政策。

這個網站

本網站沒有分析工具、沒有 Cookie、沒有指令碼，也不會從其他網站載入任何東西。

除了 Google Analytics 之外，本網站不會從其他網站載入任何東西，而 Google Analytics 也只在你接受之後才會載入，詳見上方說明。本網站本身不設定任何 Cookie。

它架設在 GitHub Pages 上，GitHub 可能會記錄造訪，詳見 GitHub 一般隱私權聲明。

聯絡方式

問題與疑問請到 github.com/tasict/Turnout/issues 回報。Issue 是公開的：請不要貼上私鑰、預共享金鑰、伺服器位址或完整的設定檔。

政策變更

本政策若有變更，新版本會公布在這一頁，並更新生效日期。本政策提供英文、繁體中文、日文與西班牙文版本；各版本如有出入，以英文版為準。
